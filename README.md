# HealthTrack – Personal Health and Fitness Management System

## Project Overview

The HealthTrack Personal Health and Fitness Management System is an ASP.NET Core MVC web application developed to manage personal health information, workout plans, diet plans, appointments, fitness progress, and communication between administrators, trainers, and clients.

## Technologies Used

- ASP.NET Core MVC
- C#
- SQL Server
- Entity Framework Core
- Bootstrap
- HTML, CSS, and JavaScript

## Database

Use the `HealthTrackDB.sql` file to create and configure the database before running the project. Update the database connection string in `appsettings.json` according to your SQL Server configuration.
